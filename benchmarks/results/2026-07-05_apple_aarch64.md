## Wall-clock — single-threaded BLAS

Median over 5 timed runs (first run discarded as warm-up). IQR is the 25–75 percentile spread. `Speedup` is R-INLA median / Julia median — values > 1 mean INLA.jl is faster.

| Dataset            | INLA.jl median ± IQR | R-INLA median ± IQR  | Speedup | mlik gap (nats) |
|--------------------|---------------------:|---------------------:|--------:|----------------:|
| Scotland BYM2      |    0.05s ±  0.01s |   27.60s ±  0.07s | 594.87x | 1.158 |
| Pennsylvania BYM2  |    0.09s ±  0.00s |   27.79s ±  0.10s | 300.31x | 0.650 |
| Meuse SPDE         |    1.60s ±  0.00s |    1.65s ±  0.01s |  1.03x | 4.736 |

The `mlik gap (nats)` column is the absolute difference between INLA.jl's `log_marginal_likelihood(res)` and R-INLA's `fit$mlik[1,1]` from the run that fed the timing — same fixture, same priors, single-figure agreement is expected.

### Improvement vs the 2026-05-14 run

Per-fit Julia allocation, before → after the Tier-3 allocation work
(bit-identical results — the `mlik gap` column above is unchanged from
2026-05-14, confirming the optimisations are correctness-preserving):

| Dataset            | 2026-05-14 | 2026-07-05 | Reduction |
|--------------------|-----------:|-----------:|----------:|
| Scotland BYM2      |   415.3 MiB |  129.6 MiB |    3.2× |
| Pennsylvania BYM2  |   836.6 MiB |  186.3 MiB |    4.5× |
| Meuse SPDE         |  3035.7 MiB | 2017.8 MiB |    1.5× |

Drivers: dropping the dense null-space bump when `H_s` is PD (ADR-045),
reusing the cached Cholesky factor for selected inversion, the in-place
`_symmetrize!`, and caching the θ-independent Sørbye–Rue `scale_factor` at
component construction. The bump-drop and factor-reuse reach the BYM2 cases
(constrained intrinsic) even though BYM2 already caches its own scaling; the
`scale_factor` cache shows most on larger stand-alone Besag/BYM fields (a
625-node constrained Besag `laplace_mode` drops 139 → 1.7 MiB, ~82×). Julia
wall-clock also improves (less allocation → less GC): Scotland 0.11 → 0.05s,
Pennsylvania 0.19 → 0.09s.

## Multi-threaded BLAS

Not yet measured. The harness sets BLAS to a single thread on both sides for the table above. A multi-threaded comparison is planned for a follow-up benchmark file once `Pkg.develop`-linked Pardiso (`GMRFsPardiso.jl`) lands as the default factorization backend.

## How to reproduce

From the repository root:

```
julia --project=benchmarks -e 'using Pkg; Pkg.instantiate()'
julia --project=benchmarks benchmarks/run.jl
```

Requires R + R-INLA on `$PATH` so RCall can `using RCall`.
