## Wall-clock — single-threaded BLAS

Median over 5 timed runs (first run discarded as warm-up). IQR is the 25–75 percentile spread. `Speedup` is R-INLA median / Julia median — values > 1 mean INLA.jl is faster.

| Dataset            | INLA.jl median ± IQR | R-INLA median ± IQR  | Speedup | mlik gap (nats) |
|--------------------|---------------------:|---------------------:|--------:|----------------:|
| Scotland BYM2      |    0.06s ±  0.00s |   28.80s ±  1.00s | 512.60x | 1.158 |
| Pennsylvania BYM2  |    0.10s ±  0.00s |   29.15s ±  0.76s | 279.42x | 0.650 |
| Meuse SPDE         |    1.55s ±  0.03s |    1.64s ±  0.04s |  1.06x | 4.736 |

The `mlik gap (nats)` column is the absolute difference between INLA.jl's `log_marginal_likelihood(res)` and R-INLA's `fit$mlik[1,1]` from the run that fed the timing — same fixture, same priors, single-figure agreement is expected.

Reported by `BenchmarkTools.@benchmark` (bytes allocated per fit, minimum across the timed samples). R-INLA memory footprint isn't reported here — `gc()` accounting in R doesn't admit a comparable single-fit number, and R-INLA shells out to a C binary that lives outside R's allocator.

### v1.1.0 vs the 2026-07-05 (v1.0.0) run — cost of the VB default

First run with `vb_correction = :mean` active by default (ADR-048
amendment, PR #34). The correction's per-design-point solves are
visible in allocations but lost in wall-clock noise:

| Dataset            | Wall-clock 07-05 → 07-06 | Alloc 07-05 → 07-06 |
|--------------------|:------------------------:|:-------------------:|
| Scotland BYM2      |      0.05s → 0.06s       |  129.6 → 152.8 MiB  |
| Pennsylvania BYM2  |      0.09s → 0.10s       |  186.3 → 219.3 MiB  |
| Meuse SPDE         |      1.60s → 1.55s       | 2017.8 → 2258.8 MiB |

The `mlik gap` column is bit-identical to 2026-07-05
(1.158 / 0.650 / 4.736 nats) — the VB correction shifts latent
summaries only and never touches `log_marginal`, so the θ-stage is
confirmed untouched. Accuracy moved the other way entirely: default
posterior means are now VB-corrected (Laplace-strategy-grade, see the
Brunei oracle gate in
`packages/LatentGaussianModels.jl/test/oracle/test_synthetic_brunei.jl`).

## Multi-threaded BLAS

Not yet measured. The harness sets BLAS to a single thread on both sides for the table above. A multi-threaded comparison is planned for a follow-up benchmark file once `Pkg.develop`-linked Pardiso (`GMRFsPardiso.jl`) lands as the default factorization backend.

## How to reproduce

From the repository root:

```
julia --project=benchmarks -e 'using Pkg; Pkg.instantiate()'
julia --project=benchmarks benchmarks/run.jl
```

Requires R + R-INLA on `$PATH` so RCall can `using RCall`.
